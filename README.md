# 01-Celta-Performance-Analysis
Performance analysis of RC Celta 2023-2024 vs 2024-2025 using Python, SQL, Power BI and Tableau

## Project Overview

This project analyses the performance of RC Celta during 2023-2024 vs 2024-2025 seasons through a comparative study of team statistics and key performance indicators.

## Tools Used

- Python
- SQL
- Power BI
- Microsoft Excel

## Objectives

- Analyse RC Celta performance.
- Compare team statistics.
- Identify strengths and weaknesses.
- Develop visual dashboards to support decision-making.
